# FUTURE_FS_03 - Local Business Website & Live Pitch Project

## Overview

This project is a professional website developed for a local gym business as part of the Future Interns Full Stack Web Development Internship.

The website helps the business establish an online presence, showcase its services, membership plans, facilities, and provide customers with an easy way to contact the business.

## Business Information

**Business Name:** FitZone Gym

**Category:** Fitness & Health

**Location:** Vijayawada, Andhra Pradesh

## Features

* Responsive Website Design
* Home Page with Hero Section
* About Us Section
* Services Section
* Membership Plans
* Gallery Section
* Contact Form
* Mobile-Friendly Layout
* Modern User Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
